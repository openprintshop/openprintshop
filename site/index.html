An open-source order desk for 3D printing studios

Customers send a model to your Telegram bot and get an instant, slicer-accurate price. You run orders, customers, filament spools and printers from a desktop admin on the studio PC.

View on GitHub Quick start

Free software under the GNU AGPL v3.0. The user interface is in Russian for now; translations are welcome.

What it does

One bot for your customers and one admin for the studio, both served from the same PC.

For customers · Telegram bot + Mini App

Price in seconds

  • Send a model file (.stl, .3mf, .obj, .step, .zip) or a link to Printables, Thingiverse or a direct file.
  • See a 3D preview and get a price, then refine it: plastic, colour, quality, strength, quantity, urgency.
  • Cart and orders with statuses, chat with the studio, payment through Telegram Payments (with the studio's own provider), delivery options and tracking, a PDF quote.
  • A catalogue of ready-made products and a gridfinity organizer configurator.
For the studio · desktop admin

Run the whole shop

  • Order pipeline and print queue, revenue dashboard, CRM with customer history, segments, broadcasts and tasks.
  • A price formula you control: material, machine time, setup, failure buffer, markup, quantity discounts, minimum price.
  • Spool inventory with tare weights and a stock ledger, calibration notes with QR passports.
  • Owner/operator roles, white-label branding, backups including an off-site copy, self-update from git, error log.
Printers

Control and print journal

  • Elegoo Centauri Carbon 2 — the deepest integration: status, timelapses, resume from a layer.
  • Klipper / Moonraker.
  • Bambu Lab over LAN (experimental).
Slicing

Real slicer, real numbers

  • Exact grams and print time from a slicer CLI on the same PC: OrcaSlicer (recommended), ElegooSlicer or Bambu Studio.
  • A built-in estimator gives the instant first price.
Optional modules

STEP→STL conversion (FreeCAD), parametric models (OpenSCAD), a status dashboard for a TURZX 8.8" USB display, AI avatars (NVIDIA GPU), semantic catalogue search, model search across Printables and Thingiverse.

How it works

Everything runs on one always-on Windows PC in the studio; watchdog.py keeps the bot alive.

Telegram ──► bot + web server (run.py, aiogram + aiohttp) ──► SQLite (data/)
  ▲              │                │
  │              │                └─► slicer CLI (OrcaSlicer / ElegooSlicer / Bambu Studio)
  │              │                    → exact grams and print time
  │              └─► printers on your LAN (Elegoo MQTT/HTTP, Moonraker, Bambu)
  │
Mini App ◄── public HTTPS address: Cloudflare Tunnel (quick or named) or your own proxy

Quick start

You need a Windows 10/11 x64 PC that stays on, a bot token from @BotFather, your Telegram user ID (@userinfobot) and a slicer on the same PC.

Install with one command (PowerShell)

The script installs Python and Git with winget if needed, clones the repository to C:\OpenPrintShop\bot, creates the virtual environment, asks for the bot token and admin IDs, and registers the watchdog to start at logon.

irm https://raw.githubusercontent.com/openprintshop/openprintshop/main/tools/installer/install.ps1 -OutFile install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1

Or install manually

git clone https://github.com/openprintshop/openprintshop.git
cd openprintshop
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
copy .env.example .env     # set BOT_TOKEN and ADMIN_IDS
.\.venv\Scripts\python run.py

Open it

Send /start to your bot. On the studio PC the desktop admin is at http://127.0.0.1:8081/app/desk/. Prices, plastics, printers, branding, payments and delivery are configured in the admin UI.

Developing on Linux or macOS? See the step-by-step local setup guide (in Russian) with test results and known issues outside Windows.
